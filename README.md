# assignment2-hh

The dataset used here is the penguins dataset, which is a csv file. The data contains penguins data by species, island, bill length, bill depth, sex, year, etc. The data analysis script does three things. First it loads the penguins csv. Second, it provides summary statistics for the dataset. Third, we produce a statistic of the mass of penguins by species. Lastly, we save the output and print the mass by species and summary stats figures.
